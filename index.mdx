Earth Query Lens is a fully client-side platform for querying and analyzing satellite imagery using large multimodal AI models. Upload GeoTIFF, SAR, or optical images and ask questions in plain language — the app processes everything directly in your browser via the Gemini Vision API, with no server infrastructure needed.

## What you can do

<CardGroup cols={3}>
  <Card title="Ask questions" icon="message">
    Type natural-language queries like "Describe this scene" or "Detect all water bodies" against any uploaded satellite image.
  </Card>
  <Card title="Detect change" icon="arrows-rotate">
    Upload a Pre-event and Post-event image pair to trigger bi-temporal change detection with evidence fusion.
  </Card>
  <Card title="Select from map" icon="map">
    Use the embedded CesiumJS globe to draw a region of interest and send a screenshot directly to the chat for analysis.
  </Card>
  <Card title="GeoTIFF support" icon="file-image">
    Drag and drop raw GeoTIFF and SAR files — the app decodes and normalizes them in-browser using geotiff.js.
  </Card>
  <Card title="Visual grounding" icon="crosshairs">
    See bounding boxes drawn on the image for every detected feature returned by the model.
  </Card>
  <Card title="Zero backend" icon="bolt">
    All inference is executed via direct Gemini API calls from the browser. No Python server, no Docker, no infra.
  </Card>
</CardGroup>

## Get started in three steps

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/SmartKidzee/vyomixsih.git
    cd vyomixsih
    npm install
    ```
  </Step>
  <Step title="Add your Gemini API key">
    Create a `.env.local` file at the project root and add your key from [Google AI Studio](https://aistudio.google.com/apikey):
    ```env .env.local
    VITE_GEMINI_API_KEY=AIzaSy_YOUR_KEY_HERE
    ```
  </Step>
  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```
    Open `http://localhost:3000`, upload a satellite image, and start querying.
  </Step>
</Steps>

<Note>
  Earth Query Lens runs entirely in your browser. Your images and API key never leave your machine — all requests go directly from your browser to the Gemini API.
</Note>
